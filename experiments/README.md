# Earlier landscape experiments

These snapshots preserve the designs that led to the current renderer. Every experiment uses the same **fictional 1,417 commits across 269 active days**, covering October 26, 2025 through October 24, 2026. They are fixed examples, with no GitHub connection or automatic refresh.

| Experiment | What it explores | Build tools |
| --- | --- | --- |
| [Weekly landscape](weekly/) | The first green and light-paper designs, with weekly peaks, a fixed daily calendar, and desktop/mobile variants. | Python 3 |
| [Original green](original-green/) | The dark jade monthly landscape, attached labels, connected shore, parallax, trees, clouds, and fish. | Python 3 |
| [Original engine](original-engine/) | Lingdong Huang's original drawing routines, including people, ferries, pavilions, and pagodas. | Node.js and Python 3 |

Each folder contains its source, sample data, generated SVGs, build commands, and attribution. The historical headers, date ranges, and decoration remain part of these snapshots. Use the [current project](../) for the maintained renderer and its clean white and green themes.

The weekly and original-green experiments adapt techniques from [Lingdong Huang's {Shan, Shui}*](https://github.com/LingDong-/shan-shui-inf). The original-engine experiment executes pinned, unmodified upstream drawing code. Each folder retains the relevant MIT notice.

These experiments were developed locally before the standalone repository existed. Importing them preserves their source and outputs without inventing earlier Git commits.
