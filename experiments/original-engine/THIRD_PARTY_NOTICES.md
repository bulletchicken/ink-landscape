# Original artwork and code

This version executes the drawing routines from **{Shan, Shui}*** by **Lingdong Huang**, rather than reimplementing their appearance. The upstream source is preserved in `vendor/index.html`, pinned to commit `9f754d2b2e73495db7883d4d4055a7b0903b0454`. The original license is preserved in `vendor/LICENSE`.

The commit aggregation, composition parameters, README frame, SVG paper grain, and repeating animation wrapper are additions for this mockup. All activity data is fictional.

Original repository: [LingDong-/shan-shui-inf](https://github.com/LingDong-/shan-shui-inf).
